# AI-assisted software projects

I build software with AI coding assistants (mainly Claude and ChatGPT). I design the system, decide what it should do, review and test the code, and run it day to day; the AI writes much of the first draft. Everything in this section is labelled that way.

| Project | What it does | Stack | Code |
|---|---|---|---|
| **Jordan OS** | A personal "second brain": an Obsidian vault on GitHub is the single source of truth, and several AI assistants read from and write to it through an MCP server and automation. Changes from each assistant go to its own branch and are merged automatically. | Obsidian, GitHub, MCP (Model Context Protocol), n8n | Being cleaned for publishing |
| **Smart home** | Home Assistant on a Raspberry Pi controlling IKEA Trådfri lights and Sonoff smart plugs, multi-room AirPlay audio on Raspberry Pi Zero 2 W boards (Shairport Sync), and wall-tablet dashboards. | Home Assistant, Raspberry Pi, YAML | Being cleaned for publishing |
| **Career-planning dashboards** | Interactive dashboards comparing engineering job demand, master's programmes and entry-level pay across countries. | HTML, JavaScript, charts | Being cleaned for publishing |

Before any of this code is published I remove API keys, tokens, home network details and personal data.

# Industrial Robot Programming (ATR0030 Robotics, TalTech, autumn 2026)

Programs I wrote for two industrial robot arms in the ATR0030 Robotics labs. Each folder has the program and a short explanation; the full lab reports are in [`docs/coursework-reports/`](../docs/coursework-reports/).

| Folder | Robot | Language | Task |
|---|---|---|---|
| [`abb-robotstudio-rapid/`](abb-robotstudio-rapid/) | ABB IRB 1600 (6-axis) | RAPID, ABB RobotStudio | Draw a circle and my initials "JB": simulated in RobotStudio, then debugged and run on the real robot at 100 % speed |
| [`mitsubishi-melfa-basic/`](mitsubishi-melfa-basic/) | Mitsubishi RV-2AJ (5-axis) | MELFA BASIC IV, CIROS Studio | Pick-and-place a workpiece across four stations with a gripper |
